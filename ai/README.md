# AI Project Workspace

Esta carpeta concentra los documentos de planificación, análisis y decisiones generados con asistencia de IA para este proyecto.

## Convenciones

- Los documentos deben explicar el objetivo, el contexto, las decisiones y la verificación esperada.
- No guardar secretos, tokens, credenciales ni datos sensibles.
- Mantener los planes históricos en lugar de sobrescribirlos cuando una decisión importante cambie.
- El código de producción permanece fuera de esta carpeta.

- `plan-implementacion-portfolio.md`: plan para preparar el proyecto para exhibición profesional en GitHub.
